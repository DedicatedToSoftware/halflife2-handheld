# Half-Life 2 for handhelds

Half-Life 2, Lost Coast, Episode One and Episode Two on RK3326 and up handheld gaming devices.

## Install

1. Download the latest zip from [Releases](../../releases/latest).
2. Unzip it into your `ports` folder.
3. Copy these folders from your own Steam install of Half-Life 2 into
   `ports/halflife2/`:
   - `hl2`
   - `platform`
   - `lostcoast`
   - `episodic`
   - `ep2`
4. Start it from the Ports menu.

Be sure you have downloaded the "steam_legacy" version of Half-Life 2. In steam, right click on Half-Life 2, click Properties, click Game Versions & Betas, and select steam_legacy from the list.

## Problems

Please open an [issue](../../issues). Include your device and firmware, and attach the log from your last run if you can. It's `log.txt` in the game's folder, e.g. `ports/halflife2/hl2/log.txt`.
